# Pomo Android

Android version of Pomo, packaged with Capacitor.

- Android package: `com.es419.pomo`
- Uses the existing Pomo Firebase backend
- GitHub Actions builds an installable debug APK on every push to `main`

## Download the APK

Open **Actions → Build Android APK**, open the latest successful run, and download the **pomo-android-apk** artifact.
